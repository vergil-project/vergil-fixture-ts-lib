    API¶

    Everything public is exported from the package's one entry point, vergil-fixture-ts-lib (src/index.ts). The build emits it to dist/, with declaration files beside the JavaScript.

    Greetings¶

    greet¶

    function greet(name: string): string;

    Greets name, trimmed of surrounding whitespace. A blank name greets the world.

    import { greet } from "vergil-fixture-ts-lib";

greet("Ada"); // "Hello, Ada"
greet("  Grace "); // "Hello, Grace"
greet(""); // "Hello, world"

    parseGreeting and Greeting¶

    function parseGreeting(json: string): Greeting;

interface Greeting {
  readonly name: string;
  readonly punctuation?: string;
}

    parseGreeting reads a greeting from a JSON object with a required string name and an optional string punctuation, and trims the name. It checks the object's shape with zod.

    import { parseGreeting, renderGreeting } from "vergil-fixture-ts-lib";

const greeting = parseGreeting('{"name": "Ada", "punctuation": "!"}');
renderGreeting(greeting); // "Hello, Ada!"

    It throws a GreetingError whose kind is:

    • "json" when the input is not JSON;
    • "shape" when the JSON is not an object, has no string name, has a punctuation that is not a string, or has any other field;
    • "blank-name" when the name is empty or only whitespace.

    renderGreeting¶

    function renderGreeting(greeting: Greeting): string;

    The greeting as text: greet of its name, then its punctuation.

    import { renderGreeting } from "vergil-fixture-ts-lib";

renderGreeting({ name: "Ada", punctuation: "!" }); // "Hello, Ada!"
renderGreeting({ name: "Ada" }); // "Hello, Ada"

    GreetingError and GreetingErrorKind¶

    type GreetingErrorKind = "json" | "shape" | "blank-name";

class GreetingError extends Error {
  readonly kind: GreetingErrorKind;
}

    The error parseGreeting throws. kind says why the input was rejected, and cause carries the underlying JSON or zod error where there is one.

    Text¶

    wordCount¶

    function wordCount(text: string): number;

    Counts the whitespace-separated words in text.

    import { wordCount } from "vergil-fixture-ts-lib";

wordCount("the quick  brown fox"); // 4
wordCount(""); // 0

    initials¶

    function initials(text: string): string;

    The upper-cased first letter of each whitespace-separated word in text.

    import { initials } from "vergil-fixture-ts-lib";

initials("Ada Lovelace"); // "AL"
initials("émilie du châtelet"); // "ÉDC"

    reverseWords¶

    function reverseWords(text: string): string;

    The whitespace-separated words of text in reverse order, joined by single spaces.

    import { reverseWords } from "vergil-fixture-ts-lib";

reverseWords("the quick  brown fox"); // "fox brown quick the"
reverseWords("   "); // ""

    longestWord¶

    function longestWord(text: string): string;

    The longest whitespace-separated word in text, measured in characters (code points). On a tie it gives the first such word, and for blank text "".

    import { longestWord } from "vergil-fixture-ts-lib";

longestWord("the quick  brown fox"); // "quick"
longestWord("   "); // ""

    shortestWord¶

    function shortestWord(text: string): string;

    The shortest whitespace-separated word in text, measured in characters (code points). On a tie it gives the first such word, and for blank text "".

    import { shortestWord } from "vergil-fixture-ts-lib";

shortestWord("the quick  brown fox"); // "the"
shortestWord("   "); // ""

    uniqueWords¶

    function uniqueWords(text: string): string[];

    The distinct whitespace-separated words of text, in the order each first appears. Words are compared exactly, so "The" and "the" are different words. For blank text it gives [].

    import { uniqueWords } from "vergil-fixture-ts-lib";

uniqueWords("the cat saw the  dog"); // ["the", "cat", "saw", "dog"]
uniqueWords("   "); // []

    repeatedWords¶

    function repeatedWords(text: string): string[];

    The distinct whitespace-separated words of text that occur more than once, in the order each first appears. Words are compared exactly, so "The" and "the" are different words. When no word repeats, and for blank text, it gives [].

    import { repeatedWords } from "vergil-fixture-ts-lib";

repeatedWords("the cat saw the  dog and the cat"); // ["the", "cat"]
repeatedWords("   "); // []

    capitalizeWords¶

    function capitalizeWords(text: string): string;

    The whitespace-separated words of text, each with its first character (code point) upper-cased and the rest left as they are, joined by single spaces. For blank text it gives "".

    import { capitalizeWords } from "vergil-fixture-ts-lib";

capitalizeWords("the quick  brown fox"); // "The Quick Brown Fox"
capitalizeWords("   "); // ""

    truncateWords¶

    function truncateWords(text: string, count: number): string;

    The first count whitespace-separated words of text, joined by single spaces. When text has fewer than count words it gives all of them, and for a count of 0 it gives "". It throws a RangeError when count is not a non-negative integer.

    import { truncateWords } from "vergil-fixture-ts-lib";

truncateWords("the quick  brown fox", 2); // "the quick"
truncateWords("the quick  brown fox", 9); // "the quick brown fox"

    countWord¶

    function countWord(text: string, word: string): number;

    How many times word occurs among the whitespace-separated words of text. Words are compared exactly and whole, so neither "The" nor "then" counts as "the". It gives 0 when word does not occur, and throws a RangeError when word is empty or contains whitespace.

    import { countWord } from "vergil-fixture-ts-lib";

countWord("the cat saw the  dog", "the"); // 2
countWord("the cat", "dog"); // 0

    wordLengths¶

    function wordLengths(text: string): number[];

    The length of each whitespace-separated word of text, in order, measured in characters (code points), so a character outside the Basic Multilingual Plane counts once. For blank text it gives [].

    import { wordLengths } from "vergil-fixture-ts-lib";

wordLengths("the quick  brown fox"); // [3, 5, 5, 3]
wordLengths("   "); // []

    firstWord¶

    function firstWord(text: string): string;

    The first whitespace-separated word of text, ignoring any leading whitespace. For blank text it gives "".

    import { firstWord } from "vergil-fixture-ts-lib";

firstWord(" the quick  brown fox"); // "the"
firstWord("   "); // ""

    lastWord¶

    function lastWord(text: string): string;

    The last whitespace-separated word of text, ignoring any trailing whitespace. For blank text it gives "".

    import { lastWord } from "vergil-fixture-ts-lib";

lastWord("the quick  brown fox "); // "fox"
lastWord("   "); // ""

    averageWordLength¶

    function averageWordLength(text: string): number;

    The mean length of the whitespace-separated words of text, measured in characters (code points), so a character outside the Basic Multilingual Plane counts once. For blank text it gives 0.

    import { averageWordLength } from "vergil-fixture-ts-lib";

averageWordLength("the quick  brown fox"); // 4
averageWordLength("   "); // 0

    toSlug¶

    function toSlug(text: string): string;

    text as a lower-case, hyphen-separated slug, by change-case's kebabCase.

    import { toSlug } from "vergil-fixture-ts-lib";

toSlug("Hello, World"); // "hello-world"
toSlug("wordCount"); // "word-count"

    toIdentifier¶

    function toIdentifier(text: string): string;

    text as a camel-case identifier, by change-case's camelCase.

    import { toIdentifier } from "vergil-fixture-ts-lib";

toIdentifier("word count"); // "wordCount"
toIdentifier("reverse-words"); // "reverseWords"
